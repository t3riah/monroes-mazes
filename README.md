# Monromi's Mazes

Live: https://mazes.no13thfloor.org

A single-file interactive maze explorer built around sacred geometry and
physics: procedurally generated mazes (9x9 to 31x31), collect the constants
Phi, c, and h-bar plus a key to open the Metatron Gateway, with a "What Is"
primer, Harmonic Codex labs (Chladni plate, double-slit, sacred geometry),
a Cosmic Hub for tier / mode / theme, and earned badges saved on the
player's device only (localStorage key `monromi_mazes_badges`).

Modes: Classic Explorer, Time Trial (beat the entropy timer), Quantum Phase
(evade red anomalies). No accounts, no ads.

This is a different game from the Nov 5, 2026 Monroe's Mazes prototype
(12 fixed levels, 5x5 to 9x9, for a 4-year-old). That prototype is not in
this repo.

## Files

- `index.html` — the whole game, one file (Tailwind via CDN)
- `CNAME` — `mazes.no13thfloor.org`
- `.nojekyll` — serve as-is on GitHub Pages
